# Code of Conduct

## Expected behavior

Contributors and users are expected to:

- be respectful and constructive
- focus on technical discussion
- provide reproducible bug reports
- accept good-faith review and correction

## Unacceptable behavior

Harassment, personal attacks, discrimination, threats, deliberate disruption, or sharing private information about others are not acceptable.

## Project maintainers

Maintainers may remove comments, close discussions, or restrict participation when necessary to keep the project constructive.

Concerns can be reported privately through the GitHub repository's available contact methods.
