# Security

VANTA is designed to run locally and does not require an online account or telemetry service.

## Reporting a security issue

Please do not publish exploitable details in a public issue.

For a real security problem, contact the project maintainer privately through the GitHub repository's available contact methods and include:

- affected version
- reproduction steps
- expected behavior
- actual behavior
- relevant logs or minimal proof of concept

Do not include passwords, access tokens, personal save files, or other private data.

## Local data

VANTA stores user data locally. Save files should be treated as user-controlled input and are validated before being accepted by the application.
